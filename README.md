# Бой привидений

Браузерная версия настольной игры Алекса Рэндольфа «Бой привидений» (Geister / Ghosts! / Good & Bad Ghosts) для двоих
на [boardgame.io](https://boardgame.io). Сделана по образцу «Анк-Морпорка»: npm workspaces `engine` / `server` / `client`,
Koa-сервер boardgame.io раздаёт и собранный клиент, и сокеты с одного порта.

## Правила

- Поле 6×6. У каждого 8 привидений: 4 добрых (синие) и 4 злых (красные). Цвета видит только хозяин.
- Перед раундом каждый тайно решает, какие из восьми привидений в его стартовой зоне 2×4 добрые.
- Ход — одно привидение на соседнюю клетку по прямой. Шагнуть на чужое — съесть его; цвет съеденного открывается.
- Победа: съесть всех 4 добрых соперника, **или** соперник съел всех 4 ваших злых, **или** доброе привидение
  уходит с поля через угол на стороне соперника (стоит на угле — следующим ходом «Выйти с поля»).

## Матч из раундов

После победы партия не закрывается: все цвета открываются, а любой из игроков жмёт «Новый раунд» — поле
расставляется заново с тем же соперником, первым ходит по очереди. Счёт (1 : 0, 1 : 1…) и история раундов копятся
за всю комнату.

## Зрители

Ссылка `#/m/<код>/watch` (кнопка «Ссылка для зрителей» в комнате, или «Смотреть как зритель» на странице мест).
Зритель — клиент boardgame.io без `playerID`; `playerView` отдаёт ему состояние без скрытия, поэтому он видит цвета
всех привидений. Игрокам цвета соперника не приходят вовсе (скрыты на сервере), а расстановка отправляется ходом с
`redact: true`, чтобы её не было видно в логе.

Учтите: зрительская ссылка открыта всем, у кого есть код комнаты, — игрок, открыв её во второй вкладке, тоже увидит
цвета соперника.

## Запуск

```bash
npm install
npm run build
npm start            # http://localhost:3001 — клиент и сервер на одном порту
```

Разработка: `npm run dev:server` + `npm run dev:client` (Vite на 5173). Тесты движка: `npm test`.

Встраивание в платформу Zarya: `?name=<ник>` подставляет имя, `?embed=1` прячет ссылки «на главную»;
служебные маршруты `/platform/...` включаются переменной `PLATFORM_SECRET`. Партии хранятся в `data/matches`
(переменная `MATCHES_DIR`).
